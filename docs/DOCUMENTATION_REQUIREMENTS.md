#### Пример:
```markdown
#### `ACTION_SCRIPT_RUN`

Выполнение скрипта.

**Запрос:**
```json
{
  "type": "ACTION_SCRIPT_RUN",
  "id": "uuid-скрипта"
}
```

**Параметры:**
- `id` (string, обязательное) - UUID скрипта

**Ответ:**
Сервер не отправляет явного подтверждения. Вместо этого транслируются обновления состояния устройств.

**Код:** `src/controllers/service.js:3158-3173`
```

### 2. Примеры кода

#### Обязательно:
- ✅ Рабочие примеры на Python и/или JavaScript
- ✅ Полные примеры (не фрагменты)
- ✅ Обработка ошибок
- ✅ Комментарии к ключевым моментам

#### Пример:
```markdown
### Python

```python
import asyncio
import json
import websockets

async def run_script(script_id: str):
    uri = "ws://192.168.88.4:3000"
    async with websockets.connect(uri) as websocket:
        command = {
            "type": "ACTION_SCRIPT_RUN",
            "id": script_id
        }
        await websocket.send(json.dumps(command))
        
        # Ожидание обновлений
        response = await asyncio.wait_for(websocket.recv(), timeout=5.0)
        print(json.loads(response))

asyncio.run(run_script("83db5b75-fa69-42f9-bd57-ee9f33d59ed7"))
```
```

### 3. Предупреждения и важные замечания

#### Обязательно:
- ✅ Выделять критически важную информацию
- ✅ Использовать эмодзи ⚠️ для предупреждений
- ✅ Объяснять последствия неправильного использования

#### Пример:
```markdown
**⚠️ КРИТИЧЕСКИ ВАЖНО: Session ID добавляется gateway сервером**

**Клиент НЕ должен добавлять session ID к сообщениям!**

```python
# ✅ ПРАВИЛЬНО - отправляем чистый JSON
await websocket.send(json.dumps({
    "type": "ACTION_SCRIPT_RUN",
    "id": "script-uuid"
}))

# ❌ НЕПРАВИЛЬНО - НЕ добавляйте session ID!
session_id = "123e4567-e89b-12d3-a456-426614174000"
await websocket.send(session_id + json.dumps({...}))
```
```

### 4. Описание ошибок

#### Обязательно:
- ✅ Типичные ошибки и их причины
- ✅ Способы диагностики
- ✅ Решения проблем
- ✅ Примеры из логов

#### Пример:
```markdown
### Ошибка: Двойной session ID

**Проблема:** Клиент добавляет session ID, gateway тоже добавляет → двойной префикс

**Симптомы:**
```
SyntaxError: Unexpected token 'd', "d2422891-6"... is not valid JSON
```

**Решение:** Отправлять чистый JSON, gateway сам добавит session ID
```
