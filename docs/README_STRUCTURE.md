# Структура README файлов

В проекте используется иерархия README файлов для удобной навигации:

## 📄 README.md (корень проекта)
**Назначение:** Основной README проекта  
**Содержание:**
- Описание проекта и архитектуры
- Инструкции по установке и запуску
- Ссылки на документацию и скрипты

**Ссылки на:**
- `docs/README.md` - документация
- `scripts/README.md` - скрипты
- `docs/SCRIPTS_STRUCTURE.md` - структура скриптов

## 📄 docs/README.md
**Назначение:** Навигация по документации  
**Содержание:**
- Ссылки на все документы в папке `docs/`
- Организация по категориям (быстрый старт, руководства, развёртывание)

**Ссылки на:**
- Все MD файлы в папке `docs/`
- Основной README: `../README.md`

## 📄 scripts/README.md
**Назначение:** Документация по скриптам  
**Содержание:**
- Описание всех скриптов в папке `scripts/`
- Примеры использования
- Переменные окружения

**Ссылки на:**
- Документацию API в `docs/`

## 📄 archive/README.md
**Назначение:** Описание архива  
**Содержание:**
- Структура архива временных скриптов
- Примечание о том, что это архив

## Рекомендации

✅ **Хорошо:**
- Каждая папка имеет свой README для навигации
- Основной README содержит ссылки на все остальные
- Нет дублирования информации

❌ **Плохо:**
- Дублирование одного и того же контента в разных README
- Отсутствие ссылок между README
- README без чёткого назначения
