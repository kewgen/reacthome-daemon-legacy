## 💡 Причины несоответствий

### 1. Датчик имеет master, но не в temperature_ext[]

**Как возникает:**
- Датчик был физически подключен к 1-Wire шине модуля
- Система автоматически обнаружила датчик и установила `master`
- НО: датчик не был добавлен в `temperature_ext[]` конфигурации

**Последствия:**
- Датчик может передавать данные
- Но система может его игнорировать при опросе
- Несоответствие в логике работы с датчиками

### 2. Почему датчики офлайн

**Возможные причины:**
- Датчики физически отключены
- Неисправность 1-Wire шины
- Датчики были удалены, но остались записи в БД
- Неправильная конфигурация DI/4 канала

## 🔧 Решение

### Вариант 1: Добавить датчики в temperature_ext[]

**Для S4 Душ:**

```javascript
// Подключаемся к модулю через WebSocket
const device = await getDevice('80:98:67:45:dc:23');

// Добавляем датчик
device.temperature_ext.push('28:aa:50:07:c5:03:c0:2c');

// Сохраняем изменения
await updateDevice('80:98:67:45:dc:23', device);
```

**Для S3 "di4 ?":**

```javascript
const device = await getDevice('80:d8:e5:2f:39:67');

// Добавляем все 11 датчиков
const missingIds = [
  '28:38:7e:2d:a3:42:02:b8',
  '28:38:be:26:a3:42:02:b8',
  '28:38:be:96:51:21:01:bc',
  '28:38:be:96:51:21:02:b8',
  '28:38:be:96:51:45:02:b8',
  '28:38:be:96:51:a1:02:b8',
  '28:38:be:96:91:42:02:b8',
  '28:38:be:96:a1:42:02:b8',
  '28:70:7c:2d:a3:42:02:b8',
  '28:74:7c:2d:a3:42:02:b8',
  '50:70:7c:2d:a3:42:02:b8'
];

missingIds.forEach(id => {
  device.temperature_ext.push(id);
});

await updateDevice('80:d8:e5:2f:39:67', device);
```

### Вариант 2: Удалить поле master у датчиков

**Если датчики действительно не используются:**

```javascript
// Для S4 Душ
const sensor1 = await getDevice('28:aa:50:07:c5:03:c0:2c');
delete sensor1.master;
await updateDevice('28:aa:50:07:c5:03:c0:2c', sensor1);

// Для S3 "di4 ?" (все 11 датчиков)
for (const sensorId of missingIds) {
  const sensor = await getDevice(sensorId);
  delete sensor.master;
  await updateDevice(sensorId, sensor);
}
```

### Вариант 3: Полностью удалить неиспользуемые датчики

**Если датчики точно не нужны:**

```javascript
// Удаляем датчики из БД
await deleteDevice('28:aa:50:07:c5:03:c0:2c');

// Или для всех 11 датчиков S3
for (const sensorId of missingIds) {
  await deleteDevice(sensorId);
}
```

## 📋 Рекомендации

### Для S4 Душ (28:aa:50:07:c5:03:c0:2c)

**Проверить:**
1. ✅ Датчик физически подключен?
2. ✅ Датчик работает? (66.66°C - аномальное значение)
3. ✅ Датчик нужен в системе?

**Действия:**
- Если датчик нужен → Добавить в `temperature_ext[]` и проверить работу
- Если датчик неисправен → Заменить или удалить из БД
- Если датчик не нужен → Удалить поле `master` или удалить из БД

### Для S3 "di4 ?" (11 датчиков)

**Проверить:**
1. ✅ Модуль правильно назван? ("di4 ?" - подозрительное название)
2. ✅ Все датчики офлайн - возможно, модуль не работает?
3. ✅ -0.06°C - это дефолтное значение для офлайн датчиков?

**Действия:**
- **Если это тестовый модуль** → Удалить все неиспользуемые датчики
- **Если модуль рабочий** → Добавить датчики в `temperature_ext[]` и проверить подключение
- **Если датчики старые** → Очистить БД от неиспользуемых записей
