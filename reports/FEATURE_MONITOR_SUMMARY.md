### 2. Применены улучшения в event-logger.js

**Файл:** `src/logging/event-logger.js`

**Изменения:**

#### Защита от DoS атак
```javascript
const MAX_MESSAGE_SIZE = 10 * 1024 * 1024; // 10MB

ws.on('message', (data) => {
  const dataString = data.toString();
  if (dataString.length > MAX_MESSAGE_SIZE) {
    logError(`WebSocket message too large (${dataString.length} bytes), ignoring`);
    return;
  }
  // ... обработка
});
```

#### Таймаут подключения к WebSocket
```javascript
const CONNECTION_TIMEOUT = 10000; // 10 секунд

connectionTimeoutId = setTimeout(() => {
  if (ws.readyState !== WebSocket.OPEN) {
    logError(`Таймаут подключения к WebSocket после 10 секунд`);
    ws.terminate();
    // ... переподключение
  }
}, CONNECTION_TIMEOUT);
```

**Преимущества:**
- ✅ Защита от переполнения памяти
- ✅ Быстрое обнаружение проблем с подключением
- ✅ Автоматическое переподключение

## 🚀 Использование

### Запуск monitor.js

```bash
# Локальный мониторинг
node src/monitor.js

# Удалённый мониторинг
REACTHOME_WS_URI=ws://192.168.1.100:3000 node src/monitor.js

# С логированием WebSocket
WS_REQUEST_LOGGING=1 node src/monitor.js
```

### Управление

| Клавиша | Действие |
|---------|----------|
| `Tab` | Переключение между панелями |
| `↑`/`↓` или `j`/`k` | Навигация |
| `Enter` | Выбор фильтра/устройства |
| `c` | Копировать данные устройства |
| `y+c` | Копировать строку таблицы |
| `q` или `Ctrl+C` | Выход |

### Низкий приоритет

1. **Логирование WebSocket в файлы**
   - Можно включить через `WS_REQUEST_LOGGING=1`
   - Не требуется для основной работы

2. **Загрузка устройств из массивов помещений**
   - Может улучшить полноту данных
