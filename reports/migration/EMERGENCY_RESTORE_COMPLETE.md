## Исправление критических ошибок

### Проблема SQLite

**Описание:**
Модуль `src/assist/lang/ru.js` пытался обратиться к таблице `forms` в БД `var/lang/ru.db`, но таблица отсутствовала, хотя файл БД существовал (474MB).

**Решение:**
```javascript
// Безопасная инициализация с проверкой
try {
    db = sqlite(dbPath);
    const tableExists = db.prepare(`SELECT ... FROM sqlite_master ...`).get();
    if (tableExists) {
        query = db.prepare(`...`);
        isInitialized = true;
    } else {
        console.warn('[ASSIST] Таблица forms не найдена, морфология отключена');
    }
} catch (error) {
    console.warn('[ASSIST] Не удалось инициализировать морфологию:', error.message);
}
```

**Результат:**
- ✅ Ошибки SQLite больше не появляются
- ✅ Только одно информативное предупреждение при старте
- ✅ Assist работает без морфологии (graceful degradation)
