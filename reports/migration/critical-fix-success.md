## Что было исправлено

### Проблема
- **Ошибка:** `SQLiteError: no such table: forms`
- **Локация:** `src/assist/lang/ru.js:5`
- **Влияние:** Повторяющиеся ошибки в логах при каждом запуске демона
- **Критичность:** Не критично для LevelDB, но засоряло логи

### Решение
1. ✅ Добавлена безопасная инициализация с проверкой наличия таблицы
2. ✅ Добавлена обработка ошибок на всех уровнях
3. ✅ Реализован graceful degradation (морфология отключается корректно)
4. ✅ Функция `getAllForms` возвращает пустой массив при ошибках

---

## Изменения в коде

**Файл:** `src/assist/lang/ru.js`

**До:**
```javascript
const db = sqlite('./var/lang/ru.db');
const query = db.prepare(`...`); // Ошибка, если таблицы нет
```

**После:**
```javascript
// Безопасная инициализация с проверкой
try {
    db = sqlite(dbPath);
    const tableExists = db.prepare(`SELECT ... FROM sqlite_master ...`).get();
    if (tableExists) {
        query = db.prepare(`...`);
        isInitialized = true;
    } else {
        console.warn('[ASSIST] Таблица forms не найдена, морфология отключена');
    }
} catch (error) {
    console.warn('[ASSIST] Не удалось инициализировать морфологию:', error.message);
}
```
