# Changelog - monitor.js

## [1.0.13] - 2025-12-12

### Added 🐛
- **Отладочное логирование** для диагностики прямых привязок
  - `[DEBUG]` сообщения при ненайденных устройствах в каналах DO/DIM
  - Помогает диагностировать проблему с вытяжками R2
- **Статистика прямых привязок** в `buildBindingsIndex()`
  - Подсчёт прямых привязок (канал→устройство)
  - Дополняет статистику обратных привязок

### Changed 🔄
- Улучшено логирование в `getActuatorChannels()`:
  - Показывает, какие устройства не найдены в `allDevices`
  - Выводит количество доступных устройств для контекста

### Debug 🔍
- Добавлены DEBUG-сообщения для выявления причин "0 привязок" у R2
- Логи помогают понять: загружены ли вытяжки, есть ли состояния каналов

## [1.0.8] - 2025-12-12

### Added ✨
- **Алгоритм резолвинга обратных привязок** актуаторов к устройствам
- **Поддержка групп каналов** (`group/1-10`) для штор и сложного освещения
- **Глобальный индекс привязок** (`bindingsIndex`) для быстрого поиска
- **Функция `buildBindingsIndex()`** — построение индекса обратных привязок при загрузке
- **Поле `linkedDevices`** в каждом канале актуатора — массив устройств с обратными привязками
- **Подсчёт привязок** в заголовках секций (общий и по типам каналов)

### Changed 🔄
- Обновлена функция `getActuatorChannels()`:
  - Добавлена поддержка обратных привязок (reverseBindings)
  - Добавлены группы с обратными привязками
  - Каналы теперь содержат `linkedDevices` для обратных привязок
- Улучшено отображение каналов актуатора:
  - Показывается количество привязок: `Actuator channels: (5 привязок найдено)`
  - Для каждого типа: `Группы каналы: (5 привязок)`
  - Отображаются все устройства с обратными привязками
  - Поддержка типа `group` в отображении

### Documentation 📚
- Добавлены ссылки на документацию в комментариях:
  - `docs/06-devices/actuators/ACTUATOR_BINDING_RESOLUTION_ALGORITHM.md`
- Создан отчёт: `reports/MONITOR_BINDINGS_RESOLUTION_ADDED.md`

### Technical Details ⚙️
- **Алгоритм:** O(1) поиск привязок через индекс (вместо O(N) сканирования)
- **Память:** ~20-50 KB для индекса (Map<MAC, Map<channelId, devices[]>>)
- **Производительность:** Индекс строится 1 раз при загрузке

### Example 📋

**До версии 1.0.8:**
```
Actuator channels:
  Реле (DO) каналы:
    DO/1: ВКЛ → (не привязан)
    DO/2: ВКЛ → (не привязан)
    ...
```

**После версии 1.0.8:**
```
Actuator channels: (5 привязок найдено)
  Группы каналы: (5 привязок)
    GROUP/1: — → 1.R2.C.1 (curtains) / Помещение
    GROUP/2: — → 1.R2.C.2 (curtains) / Помещение
    GROUP/3: — → Старшая рулонная (curtains) / Помещение
    GROUP/4: — → Штора (curtains) / Помещение
    GROUP/5: — → Раздвижные (curtains) / Помещение
  Реле (DO) каналы: (0 привязок)
    DO/1: ВКЛ → (не привязан)
    ...
```

## Формат версионирования

Версии следуют схеме: **MAJOR.MINOR.PATCH**

- **MAJOR** (X.0.0) — несовместимые изменения API
- **MINOR** (0.X.0) — новая функциональность, обратно совместимая
- **PATCH** (0.0.X) — исправления багов, мелкие улучшения

### Повышение версии

```bash
# Патч (1.0.7 → 1.0.8) — багфиксы, мелкие улучшения
./scripts/system/copy-monitor-to-pi.sh patch

# Минор (1.0.7 → 1.1.0) — новая функциональность
./scripts/system/copy-monitor-to-pi.sh minor

# Мажор (1.0.7 → 2.0.0) — breaking changes
./scripts/system/copy-monitor-to-pi.sh major
```
