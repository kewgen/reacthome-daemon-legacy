# Аудит скрипта monitor.js для Raspberry Pi

**Дата:** 2025-01-XX  
**Скрипт:** `monitoring/scripts/monitor.js`  
**Цель:** Подготовка к тестированию на Raspberry Pi

## 1. Анализ зависимостей

### 1.1. Используемые зависимости

Скрипт использует следующие зависимости:

| Зависимость | Версия в package.json | Статус | Примечание |
|------------|----------------------|--------|------------|
| `terminal-kit` | ^3.0.0 | ✅ Установлена | Терминальный UI |
| `ws` | ^7.2.5 | ✅ Установлена | WebSocket клиент |
| `child_process` | встроенный | ✅ Встроен | Системные команды |

### 1.2. Совместимость с Raspberry Pi

**✅ Все зависимости совместимы с Raspberry Pi:**

- **terminal-kit**: Совместим с Node.js 18+ на ARM архитектуре (Raspberry Pi использует ARMv7/ARMv8)
- **ws**: Чистый JavaScript, полностью совместим с ARM
- **child_process**: Встроенный модуль Node.js

**Требования:**
- Node.js 18+ (на малинке установлен v20.19.2 ✅)
- npm 8+ (обычно устанавливается вместе с Node.js)

### 1.3. Лишние зависимости

**✅ Лишних зависимостей нет** - скрипт использует только необходимые модули:
- `terminal-kit` - обязателен для UI
- `ws` - обязателен для WebSocket соединения
- `child_process` - встроенный модуль Node.js

## 2. Системные команды

### 2.1. Копирование в буфер обмена

Скрипт использует системные команды для копирования:

| Платформа | Команда | Статус на Raspberry Pi |
|-----------|---------|----------------------|
| macOS | `pbcopy` | ❌ Не используется |
| Linux | `xclip` или `xsel` | ⚠️ Требует установки |
| Windows | `clip` | ❌ Не используется |

**Для Raspberry Pi (Linux) требуется:**

```bash
# Установка xclip (рекомендуется)
sudo apt-get update
sudo apt-get install -y xclip

# Или xsel (альтернатива)
sudo apt-get install -y xsel
```

**Текущая реализация:**
- Скрипт использует fallback: если команда недоступна, выводит текст в консоль
- Это безопасно для Raspberry Pi, но копирование в буфер не будет работать без установки `xclip` или `xsel`

### 2.2. Рекомендации

**Вариант 1:** Установить `xclip` на Raspberry Pi (рекомендуется)
```bash
sudo apt-get install -y xclip
```

**Вариант 2:** Использовать альтернативный метод копирования через SSH (если запускается удаленно)

### 3.3. Потенциальные проблемы

⚠️ **Потенциальные проблемы:**

1. **Копирование в буфер обмена:**
   - На Raspberry Pi без X11 (headless режим) `xclip`/`xsel` не будут работать
   - Решение: Fallback уже реализован (вывод в консоль)

2. **Размер терминала:**
   - При подключении через SSH размер терминала может быть неопределенным
   - Решение: Уже есть проверка и обработка изменения размера

3. **WebSocket URI:**
   - По умолчанию используется `ws://192.168.88.4:3000`
   - Для тестирования на малинке может потребоваться изменение

## 4. Подготовка к тестированию

### 4.1. Предварительные требования

**На Raspberry Pi должно быть установлено:**

```bash
# Проверка Node.js
node --version  # Должно быть v18.x.x или выше

# Проверка npm
npm --version   # Должно быть 8.x.x или выше

# Проверка зависимостей
cd /path/to/reacthome-main
npm list terminal-kit ws
```

### 4.2. Установка системных зависимостей

```bash
# Установка xclip для копирования в буфер обмена (опционально)
sudo apt-get update
sudo apt-get install -y xclip

# Проверка установки
which xclip
```

### 4.3. Настройка переменных окружения

```bash
# Если WebSocket сервер на другом адресе
export REACTHOME_WS_URI=ws://192.168.88.4:3000

# Или для локального тестирования
export REACTHOME_WS_URI=ws://localhost:3000
```

### 4.4. Запуск скрипта

```bash
# Переход в директорию проекта
cd /path/to/reacthome-main

# Запуск скрипта
node monitoring/scripts/monitor.js

# Или с указанием URI WebSocket
REACTHOME_WS_URI=ws://192.168.88.4:3000 node monitoring/scripts/monitor.js
```
