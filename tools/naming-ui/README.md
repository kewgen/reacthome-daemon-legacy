# Naming UI

Лёгкий сервис для валидации и live‑применения исправлений по именованию устройств.

Запуск:

```bash
cd tools/naming-ui
npm install
npm start
```

Примечания:
- По умолчанию демоны берутся из `ws-ssh/index.js` и сохраняются в `tools/naming-ui/known-daemons.json`.
- UI доступен на `http://localhost:3005/`.
- Применение изменений выполняется live через WebSocket gate; будьте осторожны — нет dry/fake режимов.
- Логи операций пишутся в `logs/naming-ui.log`.

Важное ограничение безопасности:
- Запросы к шлюзу допускаются только по `wss://` (TLS) к внешним хостам. Локальные `ws://localhost` / `ws://127.0.0.1` запрещены и будут отвергнуты сервером.

Перед применением изменений UI требует подтверждение.

Автор: автоматический генератор
